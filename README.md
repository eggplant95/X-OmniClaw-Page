# X-OmniClaw 论文主页

本仓库为 **X-OmniClaw** 技术报告的项目展示页（GitHub Pages），内容依据 `ominiclaw-tmp` 稿件与 [arXiv:2605.05765](https://arxiv.org/abs/2605.05765) 整理。

## 链接

- **技术报告（arXiv）**：[https://arxiv.org/abs/2605.05765](https://arxiv.org/abs/2605.05765)
- **开源代码**：[https://github.com/OPPO-Mente-Lab/X-OmniClaw](https://github.com/OPPO-Mente-Lab/X-OmniClaw)

## 本地预览

在仓库根目录用任意静态服务器打开 `index.html` 即可（或直接双击在浏览器中打开，部分相对路径脚本在 `file://` 下可能受限）。

## GitHub Pages

仓库已包含 `.nojekyll`。在仓库 Settings → Pages 中选择对应分支与目录（通常为根目录）即可发布。
